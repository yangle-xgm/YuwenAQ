- **1~6年级75篇**（都是诗歌）；
- **7~9年级60篇（段）**（除诗歌外，也选入了一些短篇散文）。

这些诗文主要供学生读读背背，增加积累，在教科书中可作不同的安排，不必都编成课文。

## 附录2 · 关于课内外读物的建议

义务教育阶段要激发学生读书兴趣，要求学生**多读书、读好书、读整本书**，养成良好的读书习惯，积累整本书阅读的经验。

阅读材料包括适合学生阅读的各类图书和报刊，下列推荐的读物仅为**举例**，可作为整本书阅读等学习任务群的内容，也可推荐学生在课外阅读：

| 类别 | 推荐举例 |
|---|---|
| 童话 | 安徒生童话、格林童话、叶圣陶《稻草人》、张天翼《宝葫芦的秘密》等 |
| 寓言 | 中国古今寓言、《伊索寓言》等 |
| 故事 | 成语故事、神话故事、民间故事、中外历史故事等 |
| 诗歌散文作品 | 鲁迅《朝花夕拾》、冰心《繁星·春水》、《艾青诗选》、方志敏《可爱的中国》、《革命烈士诗抄》、中外童谣、儿童诗歌等 |
| 长篇名著 | 吴承恩《西游记》、施耐庵《水浒传》、老舍《骆驼祥子》、罗广斌/杨益言《红岩》、埃德加·斯诺《红星照耀中国》、斯威夫特《格列佛游记》、夏洛蒂·勃朗特《简·爱》、高尔基《童年》、奥斯特洛夫斯基《钢铁是怎样炼成的》等 |
| 科普科幻作品 | 《十万个为什么》、儒勒·凡尔纳《海底两万里》等 |

**补充推荐规则**：语文教师可按照《中小学生课外读物进校园管理办法》的规定，从中外各类优秀文学作品中选择合适的读物，特别是**反映革命文化和社会主义先进文化的作品**，向学生补充推荐。各类历史、文化读物，以及介绍自然科学与社会科学常识的普及性读物等，可由语文教师和有关学科教师商议推荐。鼓励学生自主选择并相互推荐文质兼美的优秀作品。

## 附录3 · 关于语法修辞知识的说明

**教学原则**：语文课程涉及的语音、文字、词汇、语法、修辞以及文体、文学等知识内容，应根据语言文字运用的实际需要，从所遇到的具体实例出发进行指导和点拨。**要避免脱离实际运用，围绕相关知识的概念、定义进行系统、完整的讲授与操练。**

所附语法修辞知识，大致约定了教学中指导和点拨的范围；其中的有关名称，主要便于教师在引导学生认识语言现象和问题时称说。关于语言结构和运用的规律，须让学生在具有比较丰富的语言积累和良好语感的基础上，在实际运用中逐步体会把握。

**知识范围清单**：

| 类别 | 内容 |
|---|---|
| 1. 词的分类 | 名词、动词、形容词、数词、量词、代词、副词、介词、连词、助词、语气词、叹词 |
| 2. 短语的结构 | 并列式、偏正式、主谓式、动宾式、补充式 |
| 3. 单句的成分 | 主语、谓语、宾语、定语、状语、补语 |
| 4. 复句的类型 | 并列、递进、选择、转折、因果、假设、条件 |
| 5. 常用标点符号 | 句号、问号、感叹号、逗号、顿号、分号、冒号、引号、括号、破折号、省略号、书名号 |
| 6. 常见修辞手法 | 比喻、拟人、夸张、排比、对偶、反复、设问、反问 |

## 附录4 · 识字、写字教学基本字表

**功能定位**：本字表是识字、写字教学的基本字表，共 **300字**（按笔画排列）。这些字**构形简单，重现率高**，其中的大多数能成为其他字的结构成分。先学这些字，有利于打好识字、写字的基础，有利于发展识字、写字能力，提高学习效率。**这些字应作为第一学段教科书中识字、写字教学的重要内容**。

**部首变体说明**：字表中的13个字附带部首变体：
人（亻）、刀（刂）、水（氵）、手（扌）、爪（⺤）、火（灬）、心（忄）、玉（王）、肉（月）、竹（⺮）、衣（衤）、足（⻊）、金（钅）。

**数据说明**：字表按 1画至13画的笔画顺序排列全部300字。因原扫描件字表页为多栏排版，本知识库不逐字转录字符清单（避免 OCR 错字污染知识库）；如业务需逐字检索，建议从权威文本源将300字转为结构化数据（CSV/JSON，字段建议：`字 / 笔画数 / 部首变体`）后挂载。

## 附录5 · 义务教育语文课程常用字表

**功能定位**：本字表共收 **3500个常用汉字**。根据这些字在当代各类汉语阅读材料中的出现频率和汉字教学的需要，分成两个字表：

**数据说明**：同附录4，本知识库收录字表的结构与用途说明；3500字的逐字清单建议从权威文本源转为结构化数据后单独挂载（字段建议：`字 / 所属字表（一/二）/ 字频序号`）。

## 常见问答（FAQ）

**Q1：课标推荐背诵的古诗文有多少篇？**
A：推荐古诗文135篇（段）：1~6年级75篇（均为诗歌），7~9年级60篇（段）（含短篇散文）。具体篇目还可由教科书编者和语文教师补充推荐。

**Q2：第四学段需要背诵的篇目数量与学段要求中"80篇"是什么关系？**
A：学段要求（分册02）中各学段背诵量为教学总量要求（50+50+60+80=240篇/段）；附录1的135篇是课标直接给出的古诗文推荐清单，其余篇目由教科书编者和教师推荐补充。

**Q3：课标推荐的长篇名著有哪些？**
A：《西游记》《水浒传》《骆驼祥子》《红岩》《红星照耀中国》《格列佛游记》《简·爱》《童年》《钢铁是怎样炼成的》等（仅为举例）。

**Q4：常见修辞手法考查范围？**
A：比喻、拟人、夸张、排比、对偶、反复、设问、反问共8种。

**Q5：识字、写字教学基本字表有什么用？**
A：300个基本字构形简单、重现率高、组字构词能力强，应作为第一学段教科书识字、写字教学的重要内容，先认先写，打好基础。
